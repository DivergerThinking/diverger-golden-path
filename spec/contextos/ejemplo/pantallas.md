# Pantallas del contexto «ejemplo»

Las pantallas de este contexto, que la aplicación enseña en `web/ejemplo/` (ADR 0053 del harness). El arquitecto las describe aquí y la tarea de cada historia las construye. Cada pantalla es una sección con estos campos, en este orden:

## Saludo

- **Id:** `ejemplo-saludo`
- **Quién la ve:** cualquier persona con la sesión iniciada.
- **Historias:** —
- **Operaciones:** `obtenerSaludo` (`GET /api/ejemplo/saludo`)
- **Qué enseña:** el saludo de la aplicación con el nombre de la persona.
- **Qué hace la persona:** nada; solo lo lee.
